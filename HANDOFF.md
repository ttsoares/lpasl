## 1. The project

We are redesigning **asl.org.br**, the site of Associação Software Livre.Org
(founded 2003, Porto Alegre). The current site is WordPress with the Newspaperly
theme. This is a **redesign, not a clone**: modern, vibrant, accessible, and
explicit about what ASL is — the old homepage never says it.

Reference material:

- `/home/ttsoares/ASL/asl.org.br` — mirror of the current WordPress site.
- `/home/ttsoares/ASL/midias` — supplied logo files (PNG only, no SVG).
- `PLAN.md` — goals, sitemap, old-URL redirect map, page blueprints, phases.
- `DESIGN.md` — “Sinal aberto” direction, tokens, layout rules, implementation map.

## 2. Design direction (decided)

**“Sinal aberto”** — amber as a broadcast signal on black; the binary digits from
the butterfly used as a structural rail, not decoration.

| Token | Value |
| --- | --- |
| ink | `#000000` |
| paper | `#FFFFFF` |
| sand | `#F4EDDD` |
| amber | `#FFC00F` |
| amber pressed | `#E0A800` |
| graphite | `#1C1C1C` |
| muted | `#565656` |

- **Display:** Archivo Variable, 800, width 125%, tracking −0.035em, leading 0.96.
- **Body/UI:** IBM Plex Sans Variable, 16px base, 1.6.
- **Mono:** IBM Plex Mono only for literal binary content.
- 12-column grid, 1280px max, 24px gutters, left-aligned, 7/5 asymmetric splits.
- 4px control radius, no shadows, hairline rules instead of card grids.
- One 420ms load reveal; 140ms hover; disabled under reduced motion.
- **Light and dark modes are both required.** Amber is never body text on white.

Superseded and deliberately removed: Space Grotesk + Inter, lime accent,
gradient mesh, eyebrow chips, numbered stat cards, shadow cards.

## 3. Stack

React 19.3.1 · Vite 8.3.5 · TypeScript ~7.0.2 · Material UI 9.5.0 ·
React Router 7.18.5 · Fontsource (Archivo, IBM Plex Sans, IBM Plex Mono) · oxlint.

```bash
npm install
npm run dev      # dev server
npm run build    # tsc -b && vite build
npm run lint     # oxlint
npm run preview
```

No backend, no CMS. Content is typed data under `src/content/`.

**Step 2.5 — design-rule audit**

Applied the five `design-cheat-codes` defaults to the shell:

- All control, nav, drawer and footer spacing now sits on the 8px grid
  (`8 / 16 / 24 / 32 / 48 / 64`, sections at `64 / 128`); 4px is only for
  micro-gaps and focus offsets.
- Text scale is Major Third from 16px: 16 / 20 / 25 / 31 / 39. Button padding is
  `8px 16px` (small), `8px 24px` (default) and `16px 32px` (large); the header
  CTA is 44px tall.
- `MuiPaper` has `boxShadow: none`; the drawer uses `elevation={0}` and a 1px
  divider. No pure-black shadows remain.
- Body leading is `1.6`; prose caps at `65ch` (hero 52ch, placeholder 58ch,
  footer 34ch).
- Accent (amber) measured at 3.7% of the hero viewport, under the 10% budget.
- Deliberate exceptions: display leading `0.96` and display sizes up to 96px;
  both are the “Sinal aberto” signal. Details in `DESIGN.md` → “Cheat-code
  audit (step 2.5)”.

## 9. Gotchas

- MUI v9 `Stack` does not accept `alignItems` as a prop; use `sx`.
- `MuiContainer.maxWidthLg` needed an explicit `@media (min-width:1200px)` rule
  to actually reach 1280px.
- The header nav only fits from `lg`; below that it wraps (“Quem somos”,
  “Associe-se”).
- The hero is ink in both modes, so outlined buttons there need an explicit
  white border; the app bar above it inverts with the mode.
- The hero's viewport height is `calc(100svh - 81px)`, not `100vh`: 80px header
  plus its 1px rule. If the toolbar height changes, this must change too.
- Forced line breaks in the headline use `whiteSpace: 'pre-line'` above `sm`
  only; below that the text must wrap naturally or “Software” ends up alone.
- Archivo’s width axis requires `@fontsource-variable/archivo/wdth.css`.
- Buttons are `whiteSpace: nowrap` globally (theme override). Without it, two
  buttons in a 5-column band wrapped their labels onto two lines at 1024px.
- `<details>` needs `scrollMarginTop` if a term ever gets a deep link; the current
  page has none.
- MUI numeric `width`/`height` inside `sx` are percentages. Use
  `visuallyHidden` from `@mui/utils` for screen-reader-only text, never `{ width: 1 }`.
- oxlint’s fast-refresh rule forced the colour-mode context into
  `src/app/color-mode.ts`, separate from the provider.
- `currentYear` is computed at module scope in the footer to satisfy the lint
  purity rule.
- **Never hand-roll a visually-hidden style.** `width: 1, height: 1` in MUI's
  `sx` is read as `100%` by the sizing style function and blew up the layout.
  Import `visuallyHidden` from `@mui/utils` instead.
- MUI `sx` accepts a callback (`bgcolor: (theme) => …`); used to lift an ink band
  to graphite in dark mode, where black-on-black would erase it.
- Anchor targets need `scrollMarginTop: 96` to clear the sticky header, and a
  re-scroll after `document.fonts.ready` because the web-font swap shifts them.
